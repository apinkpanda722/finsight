# PRD: Finsight

## 목표
개인이 은행/카드 CSV 명세서를 업로드하면 결정론적 파싱과 Claude 기반 컬럼 매핑/카테고리 분류로 분석해, 카테고리별 지출과 월별 추이를 계좌별로 보여주는 개인용 가계부 SaaS.

## 사용자
한국의 개인 사용자. 여러 은행/카드사에서 내려받은 CSV 거래내역을 수동으로 업로드해 지출을 파악하고 싶은 사람.

## 핵심 기능
1. 랜딩 페이지 → 회원가입(이메일 확인 필수) → 로그인 → 대시보드 전환 플로우, 비밀번호 재설정 포함
2. CSV를 Supabase Storage에 직접 업로드(서버는 signed URL만 발급) → 서버가 실제 원본을 검증 → 결정론적 CSV 파싱 + Claude(컬럼 매핑 추론, 100행 단위 카테고리 분류)로 계좌별 카테고리 지출 요약 + 월별 추이 대시보드 생성
3. Polar 기반 Pro 구독 결제(단일 recurring 상품)와, 핵심 구현이 끝난 뒤의 Vercel 배포

## 요금제
- **Free**: 계좌 1개, 카테고리별 지출 요약 + 월별 추이, **현재 달 포함 최근 3개 달**만 열람 가능(그 이전 데이터는 잠금 placeholder로 존재만 표시)
- **Pro**: 다중 계좌 등록 + 계좌별 무제한 히스토리 조회. **여러 계좌를 하나로 합산하는 통합 뷰는 MVP에 없음**(fast-follow). 이상거래·중복결제 탐지, PDF/엑셀 리포트 내보내기도 fast-follow(이번 라운드는 plan 게이팅과 데이터 모델만 준비)

## MVP 포함
- 개별 statement(업로드 건) 삭제 — 원본 Storage 파일, statement, 파생 거래를 삭제. 비용 남용 방지용 업로드 횟수 집계(`upload_usage`)는 별도로 보존
- 처리 중 멈춘 업로드에 대한 수동 재시도(retry)

## MVP 제외 사항
- 은행 계좌 자동 연동(오픈뱅킹 API) — CSV 수동 업로드만 지원
- 전체 계정/전체 데이터 삭제 — 이번 자동화 범위에서 제외, 문의 채널로 응대하되 출시 전 privacy 문서에 절차·보존 기간을 명시하고 fast-follow 최우선 항목으로 관리
- 다국어 지원, 모바일 앱
- Pro 전용 고급 분석의 실제 알고리즘(이상거래 탐지, PDF/엑셀 내보내기 생성, 다중 계좌 합산 뷰)
- Vercel 배포/연결의 조기 구축 — 핵심 구현 완료 후 진행

## 디자인
- Tailwind CSS + shadcn/ui, 미니멀
- Free/Pro 플랜 상태를 항상 명확히 표시(사이드바 배지). 제한에 도달하면 업그레이드 CTA로 자연스럽게 유도
- CSV 업로드 → 처리 상태(uploading/pending/processing/completed/failed) → 결과까지 명확히 보여주고, 멈춘 처리는 재시도 버튼을 제공
- 업로드 전 원본 CSV가 Supabase/Anthropic에 전달된다는 점을 명시적으로 안내하고 동의를 받는다
